# Hunt Vault Client

## Executar localmente

Requisitos:

- Node.js `>= 24`
- npm ou Yarn

```bash
cd client
npm install
npm run dev
```

Abra `http://localhost:5173` no navegador.

## Comandos

```bash
npm run dev
npm run build
npm run preview
npm run typecheck
npm run check:biome
npm run format
```
